# الذكاء الاصطناعي في التجزئة والاتصالات

AI in Retail and Telecommunications

مسار الطلاقة في البيانات والذكاء الاصطناعي · أكاديمية سدايا · USE-SEC-210 · المستوى 200

تختبر التنبؤات والتوصيات والأسعار المخصصة وعروض الاحتفاظ وتنبيهات الشبكة أمام خطوط الأساس والتجارب، وتفحص استخدام بيانات العملاء، وترتّب حالات الاستخدام في خريطة تدافع عنها

يختبر المديرون التجاريون ومديرو التسويق والشبكات وخدمة العملاء التنبؤات واستهداف العملاء المعرضين للانصراف وقواعد التسعير ونتائج أنظمة التوصية وتنبيهات الشبكة مقارنة بخطوط الأساس والتجارب، ويفحصون استخدام بيانات العملاء، ويبنون خريطة الفرص والمخاطر لتاجر تجزئة أو مشغل اتصالات افتراضي. أما العمل التسويقي الفردي فيغطيه المقرر USE-PRO-210.

**الصيغة:** ورشة عمل: يومان يضمان ثماني جلسات مع مختبرات، وعمل تحضيري متعقَّب، وخريطة تُناقَش

**صفحة المقرر:** https://sdaiaacademy.github.io/use-sec-210/

| LO5 | يقيس أداء أداة لاكتشاف الشذوذ في الشبكة مقارنة بالحوادث المؤكدة ويحدد عتبة للتنبيه يستطيع الفريق التعامل معها، على تنبيهات اصطناعية لمواقع أبراج الاتصالات خلال أسبوع | Applied | جدول للدقة والاستدعاء وعتبة مختارة |
| LO6 | يبني خريطة الفرص والمخاطر ترتب حالات الاستخدام بحسب القيمة المقيسة والضرر على العملاء وحقوق البيانات، استنادًا إلى ملف تعريفي لتاجر تجزئة أو مشغل اتصالات افتراضي | Performance | خريطة من صفحة واحدة تُناقَش في خمس دقائق |
