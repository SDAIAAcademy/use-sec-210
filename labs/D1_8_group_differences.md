# المختبر 1.8 · فروق الأسعار بين الفئات ومذكرة النتائج

تحسب متوسط الخصم ومؤشر السعر لكل فئة عمرية وفئة دخل الحي ونوع الجهاز ومستخدمي التقسيط، وتتتبع كل فرق إلى مكوّنه، وتكتب مذكرة نتائج بتعديل مقترح.

اليوم 1 · الجلسة 8: فروق الأسعار والعملاء الأكثر عرضة للضرر

### ستخرج من هذا المختبر بـ

- متوسط الخصم ومؤشر السعر لكل فئة: العمر، ودخل الحي، ونوع الجهاز، ومستخدمو التقسيط.
- لكل فرق كبير: المكوّن في القاعدة الذي يصنعه.
- مذكرة نتائج من صفحة واحدة بتعديل مقترح وطريقة قياس أثره.

## ما تحتاجه

[**start/offers_with_groups.csv**قسائم الشهر لـ6,000 عميل مع فئاتهم ومكونات الخصم الخمسة](https://sdaiaacademy.github.io/use-sec-210/labs/files/start/offers_with_groups.csv) [**pricing/saerak_rule.txt**وصف القاعدة](https://sdaiaacademy.github.io/use-sec-210/labs/files/pricing/saerak_rule.txt)

يبدأ المختبر من ملف جاهز، فلا يحتاج نتيجة المختبر 1.7. الأداة جدول بيانات (جدول محوري أو `AVERAGEIF`). سياسة الذكاء الاصطناعي: مساعد معلّم.

## الخطوات

### 1 · افهم الأعمدة 3 دقائق

`F` نسبة الخصم، و`G` مؤشر السعر (100 ناقص الخصم: ما يدفعه العميل من كل 100 ريال)، و`H` إلى `L` مكونات الخصم: من السجل، ومن الموقع، ومن الجهاز، ومن التقسيط، ومن العمر. مجموع المكونات هو الخصم (ولا يقل عن صفر).

### 2 · متوسط الخصم لكل فئة 7 دقائق

```
# ملف: offers_with_groups.csv
=AVERAGEIF(B:B,"60+",F:F)       age band
=AVERAGEIF(C:C,"low",F:F)       district income
=AVERAGEIF(D:D,"ios",F:F)       device
=AVERAGEIF(E:E,1,F:F)           instalments users
```

| الفئة | العدد | متوسط الخصم (%) | مؤشر السعر |
| --- | --- | --- | --- |
| العمر 18-29 / 30-44 / 45-59 / 60+ |  |  |  |
| دخل الحي low / middle / high |  |  |  |
| الجهاز ios / android_new / android_old |  |  |  |
| التقسيط 0 / 1 |  |  |  |

### 3 · من أين يأتي الفرق 6 دقائق

لكل فئة يظهر فيها فرق أكبر من نقطة، احسب متوسط كل مكوّن. المكوّن الذي يتغير أكثر بين الفئات هو مصدر الفرق.

```
# ملف: offers_with_groups.csv
=AVERAGEIF(C:C,"low",I:I)       location part, low-income districts
=AVERAGEIF(C:C,"high",I:I)      location part, high-income districts
```

انتبه للمكوّن الذي لا يذكر الفئة باسمها ويصنع الفرق بينها: هذا متغير وكيل.

### 4 · مذكرة النتائج 5 دقائق

مذكرة لروزان الباهلي، ونسخة لوصال الحبشان، بثلاثة أجزاء: الفرق بالأرقام، ومصدره في القاعدة، ومن يتضرر ولماذا يهم ذلك عند فئة أكثر عرضة للضرر.

### 5 · التعديل المقترح 4 دقائق

اقترح تعديلًا واحدًا محددًا، وكيف يُقاس أثره بعد شهر: على الفروق بين الفئات، وعلى الهامش.

### ✱ تمرين إضافي

أضف عمودًا للخصم دون مكوّني العمر والتقسيط (`=MAX(0,H2+I2+J2)`)، وأعد حساب الفرق بين الأعمار وبين مستخدمي التقسيط وغيرهم.

## أسئلة تحقق

1. أي فئة تدفع أكثر، وبكم نقطة؟
2. لماذا يصنع مكوّن الموقع فرقًا بين أحياء الدخل، مع أن القاعدة لا تقرأ الدخل؟
3. لماذا لا يكفي حذف عمود العمر من البيانات لإزالة الفرق؟
